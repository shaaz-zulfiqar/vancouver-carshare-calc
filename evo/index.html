Promo Code FAQ

What does the promo code do?

Entering it in the “Promo Code” field on the “Promos & Savings” page of the application waives Evo's registration fee and credits your account with 60 minutes of drive time.

How much is Evo registration?

Evo charges a one-time registration fee of $35 (BCAA members register free), which the code waives for eligible new members.

Can existing Evo members use this code?

Promo codes are typically for new signups. If you already have an Evo account, check with Evo before assuming it applies.
