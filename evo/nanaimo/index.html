Evo Return in Nanaimo round trips from the ferry terminal

How Evo Return works at the Nanaimo Hullo ferry terminal, and what a booking costs.

ℹ

This is not a free-floating Home Zone. Evo Return is a round-trip service: you pick the car up and bring it back to the same reserved spot at the Hullo ferry terminal.

How Evo Return works

  • Reserve in the Evo app up to 30 days ahead, which guarantees a car when you arrive.
  • Bookings run from 1 hour to 30 days.
  • You get a digital key shortly before the booking starts.
  • Every trip starts and ends in the same Return Zone, which only Evo Return cars use.

What it costs

  • Evo’s regular rates apply, with gas, insurance and unlimited kilometres included.
  • Hullo is the car-free passenger ferry between downtown Vancouver and Nanaimo, so Evo Return is for getting around after you land.
  • Evo Return also runs at King George SkyTrain station in Surrey.

Source: evo.ca/return and BCAA’s launch announcement (May 2024). Check the Evo app for current availability.
